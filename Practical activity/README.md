# Practical Activity: Build, Upload and Deploy a Website

Three starter websites built with plain HTML, CSS and JavaScript. No installs are needed.

| Folder | Website | What it practises |
|---|---|---|
| 1-portfolio | Personal portfolio | Page structure, CSS variables, responsive layout, dark mode toggle |
| 2-coffee-house | Coffee shop website | Menu filter in JavaScript, form validation, Netlify Forms |
| 3-task-tracker | Task tracker app | DOM manipulation, arrays, events, localStorage |

## Part A: Make it yours
1. Open the folder in VS Code (or any editor) and open `index.html` in your browser.
2. Change the name, text, colours and images so the site is clearly yours.
3. Add one new feature (for example a new section, a new menu item, or a "Clear all" button).

## Part B: Upload to GitHub
1. Sign in at github.com and click **New repository**. Name it (for example `my-portfolio`) and keep it **Public**.
2. Click **uploading an existing file**.
3. Open your site's folder and drag in **everything inside it** (`index.html`, `css`, `js`, `images`). `index.html` must be at the top level of the repository, not inside another folder.
4. Click **Commit changes**.

## Part C: Deploy on Netlify
1. Sign in at netlify.com with your GitHub account.
2. Click **Add new site**, then **Import an existing project**, then **GitHub**, and choose your repository.
3. Leave **Build command** empty and set **Publish directory** to `/` (or leave it blank).
4. Click **Deploy**. After about a minute you get a live link.
5. Optional: go to **Site configuration** and **Change site name** to get a cleaner address.

## Part D: Submit
- Your GitHub repository link
- Your live Netlify link
- A screenshot of the site on a phone-sized screen

Site 2 only: after deploying, submit a test booking. In Netlify, open **Forms** to see it arrive.
